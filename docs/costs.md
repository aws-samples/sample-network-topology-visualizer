# 비용

[English](costs.en.md)

실측값이 아니라 템플릿 기본값으로 계산한 추정치입니다. 가격은 리전과 시점에 따라 다릅니다. 실제 리전과 설정으로 [AWS Pricing Calculator](https://calculator.aws/) 에서 확인하세요.

요금은 리소스를 소유한 AWS 계정에, API 요청의 경우 요청을 수행한 IAM 보안 주체가 속한 계정에 청구됩니다. 스택 A 와 스택 C 는 모든 리소스(CodeBuild, Lambda, S3, CloudWatch Logs, SQS, CloudFront)를 모니터링 계정에 생성하므로 그 비용은 모니터링 계정이 부담합니다. 소스 계정에는 CloudWatch `GetMetricData` 요청 요금만 부과됩니다. 이 요청은 수집기가 각 소스 계정에서 수임한 스택 B 역할로 수행합니다. 스택 B 가 생성하는 IAM 역할은 무료입니다. 트래픽 모니터링과 사용률을 활성화하지 않으면 소스 계정에는 요금이 발생하지 않습니다.

| 항목 | 비용을 정하는 것 | 월 비용(대략) | 청구 계정 |
|---|---|---|---|
| CodeBuild 수집 (`BUILD_GENERAL1_SMALL`, 기본 1시간마다) | 빌드 분당 단가 × 회당 분 × 월 720회. 분당 $0.005(us-east-1·ap-northeast-2, 2026-09-11 AWS 가격표)에 보통 회당 2~5분이면 $0.005 × 2 × 720 = $7.20 ~ $0.005 × 5 × 720 = $18 | 약 $7 ~ $18 | 모니터링 계정 |
| Lambda (실시간 모니터링을 켠 경우): 함수 2개 — 상태 관측(1,024MB, arm64)과 화면 서명(256MB, arm64). 각각 5분마다, 그리고 이벤트가 있을 때 실행 | 호출 수 × 실행 시간 × 메모리 | 실행 시간에 따름 | 모니터링 계정 |
| S3 저장과 요청 | 시간이 지나면 늘어납니다. 빌드마다 스냅샷이 쌓이고, 산출물 버킷은 이전 버전을 남깁니다(`index.html` 과 `unsigned/` 의 이전 버전만 1일 뒤 만료). `deploy.sh` 가 만든 패키지 버킷도 이전 버전을 남깁니다 | 이력이 쌓일수록 늘어남 | 모니터링 계정 |
| CloudWatch Logs | 로그 그룹 3개(수집기·상태·서명), 기본 30일 보관(`LogRetentionDays`) | 수집·저장 GB 당 | 모니터링 계정 |
| SQS 실패 대기열 (실시간 모니터링) | 실패한 상태 관측만 담깁니다. 보통 비어 있음 | 약 $0 | 모니터링 계정 |
| CloudFront (스택 C) | 전송량과 요청 수, 그리고 로그 버킷에 쌓이는 접근 로그(기본 90일 보관) | 보는 사람 수에 따름 | 모니터링 계정 |
| CloudWatch 지표 조회 (트래픽 모니터링 또는 사용률) | 수집 주기마다 요청하는 지표 수. `GetMetricData` 는 지표 1,000개당 $0.01 이며 CloudWatch 무료 티어에 포함되지 않음. 시간 범위와 반환되는 데이터 포인트 수는 요금과 무관 | 리소스 수에 따름 | 지표를 소유한 계정 |
| 구조 수집 API 호출 (`Describe*` 등) | 과금되지 않음 | 없음 | 요금 없음 |

비용은 거의 전부 CodeBuild 실행 시간입니다. 계정·리전·리소스가 늘어 수집 1회가 1분 길어지면 월 약 $3.60($0.005 × 720) 늘어납니다. `Schedule` 을 늘리면 그만큼 줄어듭니다.
